## 四类事件的硬格式

### 普通击杀 / 爆头击杀

顺序：阶段或职责 + 击杀时血量 + 摸烟 + 武器 + 普通/爆头击杀 + 对枪。

- 有「对枪胜利」必须写「赢下对枪」。
- 有「摸烟击杀」必须写「摸烟」。
- 只有击杀行明确写「击杀时满血/剩N血」才写血量，不能用【我】反推。
- 普通击杀不能补成爆头。

### 多杀

必须出现武器、最终杀数、各组击杀的阶段或职责。首杀有「摸烟击杀」还必须写摸烟。
不同阶段必须分开，不能把首杀算进后一个阶段。
同一阶段或职责内发生两次击杀时必须明确写「双杀」，不得写成「再杀两枪」或只写「再杀」。

### 白给

带【刚刚】的行明确写「白给」时，事件行必须写「阶段+白给」，不得降级成普通死亡。
核对行的个人重点必须写「白给」，不能写「零杀普通死亡」。存活时长和装备价值可省略，
但「白给」二字不能省略。

### 死亡

- 类型为普通死亡且零杀：阶段 + 普通死亡。武器不能修饰死亡。
- 有击杀：先写击杀阶段、武器和杀数，再写死亡；带包必须写「带包阵亡」。
- 击杀时低于50血，优先写「残血」；也允许具体血量。篇幅不足时优先保留武器、杀数、残血，再省死亡阶段。
- 只有死亡动作括号明确写「击杀后被补枪」才能写「被补枪」，否则绝不能说被补。
- 「阶段不可判断」必须写「未观测开打时刻」，不能猜阶段。

带【刚刚】的行为普通死亡时，零杀事件行只能是「阶段+普通死亡」；若未观测开打，则只能是
「普通死亡，未观测开打时刻」。不得添加武器、血量变化、烟闪或其他说明。

### 回合胜利 / 回合失败

事件行必须以结算开头：

- 有获胜方式：`事件：灭队/炸弹引爆/炸弹拆除/时间到，回合胜利/失败`
- 无获胜方式：`事件：回合胜利/失败`

时间线的「炸弹已安放」只表示下包，绝不等于炸弹引爆。结算前缀写完后，只按以下第一条命中的规则续写：

1. 未观测开打：补「未观测开打时刻」；本人零杀时到此结束，不写烟、闪或普通死亡。
2. 开局一杀后马上阵亡，后来以引爆或拆除结算：到结算前缀结束，早期个人事件不是结算重点。
3. 两杀或三杀后阵亡：续写武器、分阶段杀数、随后阵亡和「有显著贡献」。四项缺一不可。
4. 存活到结算且有击杀：续写「活到」+ 阶段 + 武器 + 杀数。
5. 其余才补个人一杀或死亡。

核对行的个人重点严格对应上述选择：第2条写「省略」，第3条写「显著贡献」，第4条写「存活击杀」。
个人重点为「省略」时，事件行只能写获胜方式与回合结果，不得出现武器、击杀、爆头、对枪或阵亡。
第2条的「省略」只适用于获胜方式为炸弹引爆或炸弹拆除。获胜方式为灭队或无时绝不能套用第2条；
若时间线是一杀后很快阵亡，个人重点必须写「击杀后阵亡」，事件行必须保留阶段、武器、一杀和被补枪。

例如：灭队失败、中期AK47一杀后很快阵亡 →
`灭队，回合失败，中期AK47一杀后马上被补枪`。

获胜方式是全局结果，不能说玩家本人下包、拆包、引爆或完成灭队最后一杀。
若带【刚刚】的结算组合中同时明确出现「MVP+1」，事件行必须保留「获得MVP」；
它是可靠的个人贡献结果，但仍不能据此猜具体执行者。

## 容易漏错的反例

- 零杀普通死亡：错误 `中期用AK47普通死亡`；正确 `中期普通死亡`。武器、护甲不修饰死亡。
- 只有「摸烟击杀」没有「对枪胜利」：错误 `摸烟赢下对枪`；正确 `前期摸烟用M4A1-S普通击杀`。
- 前期摸烟一杀、反攻包点双杀后被补且回合失败：正确
  `灭队，回合失败，前期摸烟一杀，反攻包点双杀后被补`。
- 活到后期用M4A1-S一杀并获胜：不能只写回合结果；正确
  `灭队，回合胜利，活到后期用M4A1-S一杀`。
- 前期M4A1-S爆头赢下对枪，随后灭队获胜：不能只写灭队；正确
  `灭队，回合胜利，前期M4A1-S爆头赢下对枪`。
- 未观测开打且零杀普通死亡：正确 `普通死亡，未观测开打时刻`，不要写烟闪经过。
- 中期SSG 08双杀，第二杀标有「击杀时剩11血」和爆头：正确
  `中期SSG 08双杀，第二杀11血爆头`。

## 输出前六项复核

1. 回合胜负是否来自带【刚刚】的结算行，并以该结算开头；
2. 获胜方式是否真的写在该结算行，没有就不能补；
3. 多杀是否有武器、最终杀数和分阶段经过；
4. 白给是否仍明确写成白给，没有误写成普通死亡；
5. 满血/残血、对枪、摸烟、被补是否各有代码标签；没有标签是否已禁止添加；
6. 结算时两杀/三杀后阵亡是否写了「有显著贡献」；
7. 未观测开打时刻是否明确承认且没有猜阶段。

每个词都必须能在卡片找到依据。不得猜执行者、击杀者、击杀对象、敌方武器与经济、场上人数、玩家位置、
队友行为或伤害来源；不得对经济下总评；不得用「导致」「造成」「因此」补因果。

场面行第一句复述【比分】与带【刚刚】的时间线行，随后按顺序复述最多 3 条支撑事件行的记录。不要复述整条时间线，
不要写「没有发生」等否定总结，也不要反过来改变事件行重点。

## 事件必答覆盖规则（优先级高于上文所有“只能写”和“到此结束”）

程序已经把与本次焦点直接相关的罕见关系（被闪/烟雾/燃烧、换弹与弹匣、残血、道具、
MVP/助攻、拿包与炸弹计时等）算进【事件必答】。〔必答N〕是地位相同、逐项验收的原子，
不是供你挑选的素材。必须先在心里逐项打勾，再压成事件行；措辞可以合并，事实不得合并消失。
【本回合】时间线只用于核对先后与措辞，不要把清单外的旁支事件自行升级成必答项。

【事件必答】已按保留优先级从左到右排列。30 字冲突时，先把相邻原子压成短语，仍不得
漏掉任意编号；例如“被闪期间完成双杀”可压成“被闪双杀”，但不能只写“双杀”。

不得补执行者、位置、敌人或伤害来源。只有未编号的“满血”和重复阶段等修饰可以删除；
凡带〔必答N〕的内容，包括罕见关系、武器、最终多杀数、“有显著贡献”和回合结果，
一律不得删除。一个〔必答N〕内部用分号隔开的每个子项也都必须出现，不能只挑最后的
回合结果。输出前按编号和分号子项逐个复核覆盖数量。

本节是最终覆盖门，优先于上文“四类事件的硬格式”和示范：若旧格式会漏掉编号事实，
必须扩写事件行保住编号事实。例如“本回合新增助攻；灭队，回合胜利”必须同时说助攻和
回合胜利；“炸弹已安放；我方CT；炸弹引爆，回合失败”三项必须全部说。

“M4A1-S最后1发完成第3杀”不能退化成普通三杀；最后一发是核心。

# M5-T2.8 视觉考卷权威答案键

“产品负责人判定”来自产品负责人提供的快回答与慢回答，是本卷判卷权威；措辞仅作
断句，没有改写含义。离线复核由 coding agent 完成，可能出错，凡与产品负责人冲突
的条目均移入“不确定项”并注明。本卷测量画面感知；sequence 题只比较给出的稀疏
端点，不得把未采样过程、滚动记忆或完整情境理解混入评分。

## 通用判卷规则

- 快线只按“产品负责人判定”中的【核心】计算覆盖率；深线按【核心】与【细节】计算。
- 【存疑】既不要求模型提及，也不因模型提及而判为编造；若描述与画面明显冲突，仍按
  “不得出现的内容”处理。
- 现实世界型号比附——包括枪械、直升机、载具型号与瞄具品牌——一律标为【存疑】，
  不得混入【核心】或【细节】计分要点。
- “不得出现的内容”对快线和深线一视同仁。
- 模型描述 UI 布局或第一人称持枪视角，不加分也不扣分。
- 生产环境中游戏名始终由窗口标题免费获得，因此本卷不设“不给游戏名”题；知识层的
  真实对照（游戏名 vs 游戏名+知识卡）留待知识卡落地后追加变体。

“现场记录”逐字摘自 `backend/audit/m5-t1-field-test-results.md` 中产品负责人提供的
场景描述。每条判断均以 `【现场记录】` 或 `【离线复核】` 标明来源；两者的证据
范围不同时保留差异，不自行调和。文件名、文字和描述均未记录真实玩家身份。

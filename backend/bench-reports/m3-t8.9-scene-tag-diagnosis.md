# M3-T8.9 场景标签诊断与复测

## 结论

- 大狙空枪已不再读取 `_operated_weapon()`：逐帧从完整武器列表按
  `weapon_awp` 比对弹匣，并延后一帧确认击杀计数。合成回归覆盖 AWP
  开枪帧已切到手枪的情况。
- “用几枪杀人”跨帧累计的怀疑成立。真实录制一次 AK 击杀可见
  `18 → 16 → 13 → 11 → 9`，旧实现只会取最后一帧的 `11 → 9`；
  现在正确标为用弹 9 发。
- 新弹药档位为 1 / 2–5 / 6–9 / ≥10：`一发命中`、`干净解决`、
  `打了半天`、`一梭子扫死`。旧的“≥10 叫打了半天”语义不存在了。

## 大狙空枪

真实录制的可读 AWP 弹匣下降共有 3 次，均在 warmup（原始第 572、574、580 行），
且每次下一帧都增加 `round_kills`（573、575、581 行）。这也证明必须延后一帧
确认，否则会把三次实际击杀误记为空枪。正式对局没有可读的 AWP 弹匣下降。因此
修复后**正式对局事件卡命中仍为 0**：不是手持状态问题，而是这份录制没有可证实的
正式对局空枪。

新增 `awp_miss_then_death` 合成场景：两次 AWP 弹匣下降发生时均已切到副武器，
后续死亡卡包含 `大狙空枪` 与 `连续空枪`。这验证了修复后的判据和状态标签。

造成 `干净解决` 被高估。

## 性能与准确率

本轮只运行 cards-only 回放和本地测试，未调用模型：冻结答案文件按要求没有修改，
也没有自动语义评分器可把新的模型输出可靠地判为“正确/错误”。因此不能把旧的
100% / 97.5%、事件 P95 1.070 秒、平均输入 2387.3 token 伪称为本轮实测结果。
它们仍是 M3-T6.6 的历史基线；本轮准确率、模型事件 P95 与平均输入 token **未重新测得**。

卡层的变化只发生在确定性标签和 `用弹N` 数值；事件检测、policy、提示词和冻结答案均未改。
正式模型复测需要产品负责人对新的 raw 输出按冻结 key 评分后才能得出准确率变化。

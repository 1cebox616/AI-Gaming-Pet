# M3-T8.10：死亡前开火区间与复测

## 实现

- `DEATH_COMBAT_WINDOW_SECONDS = 3.0`：与连续事件段处于相同量级，只把临死前的
  近身交火算入，不把更早的试探性开枪归因给这次死亡。
- `RoundSituation` 只在本人数据帧累计三项确定性观测：本回合弹匣下降时刻、最近一次
  手持武器弹匣可读时刻、以及本回合确实开过火的武器集合。
- 这三项观测只由死亡焦点渲染消费；不产生 `events.py` 事件，也不会给存活玩家贴标签。
- 既有 `击杀后被补枪` 与 `白给` 仍先按原有事件类型渲染；新标签只追加，不覆盖。

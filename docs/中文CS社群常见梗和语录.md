# 中文 Counter-Strike 社群常见梗和语录

> 本文按中文 Counter-Strike / CS2 社群整理。圈内梗主要来自主播直播间、职业比赛名场面、选手中文外号和天梯日常。内容以“现在看直播、刷切片时仍经常出现”为标准，并非严格的梗源考据表。
>
> 尤其是玩机器直播间，大量内容属于借梗、融梗和集体二创，不一定由主播或直播间原创。[虎扑相关讨论](https://bbs.hupu.com/60674310-2.html)也提到，6657的特色正是大量复读形成集体节目效果。

## 一、最基础的中文 CS 黑话

| 梗/说法 | 含义与用法 |
|---|---|
| 白给 | 没发挥任何作用就死了，等于免费送人头、送枪。不是茄子首创，但经他直播传播出圈。[5EPlay](https://csgo.5eplay.com/article/experienced-vac-after-the-event-the-real-rebirth-of-eggplant) |
| 老六 | 躲非常规位置、绕后、阴人或专门偷背身的人。可夸意识，也可骂打法猥琐。 |
| 马枪 | 本该打中却空了很多枪：“这都能马？” |
| 干拉 | 不交闪、不封烟，直接拉出去对枪。成功叫枪硬，失败叫白给。 |
| 接力 | 队友一个接一个去送，像排队给对面刷人头。 |
| 突破口 | 总是第一个死的人。和“突破手”只有一字之差，效果截然不同。 |
| 人肉道具 | 自己冲出去吸引枪线，让队友补枪；也可说“人肉闪”。 |
| 大狙理财 | AWP价格高，因此残局没机会时保下来，避免下回合重新购买。 |
| Jame Time | 局面稍有不对就开始保枪。源自Jame极强的保枪风格。 |
| ECO能翻 | 没钱局也要相信翻盘；常见完整版“人生何处不青山，下把ECO我能翻”。 |
| 有为青年，不起雷钳 | 忘买拆弹器；一般等到最后拆不掉包时刷。 |
| 旋转/陀螺 | 指开自动转圈瞄准一类暴力外挂。 |
| 科技/高科技 | 外挂的委婉称呼。“对面科技领先。” |
| 锁了 | 枪法突然准得离谱，像开了自瞄；不一定真的指控开挂。 |
| 便秘进攻 | 进攻方一直默认、架枪、不敢进点，最后二十秒才匆忙行动。 |
| 折磨局 | 比分胶着、不断加时，或者两队失误频出，观众和选手一起受刑。 |
| 下饭 | 操作失误很多，很适合观众边吃饭边看。 |
| 白忙活 | 打了很久、追平甚至加时，最后仍然输掉。 |
| de_airport | 大赛早早被淘汰，去“机场地图”备战回家。 |

## 二、茄子系经典语录

茄子的影响很大，“白给”“WDNMD”“真就……”等已经从CS圈扩散到整个游戏社区。[新浪游戏的早期总结](https://games.sina.cn/esports/2019-04-28/edetail-ihvhiqax5463431.d.html)也收录了其中几句。

| 梗/语录 | 通常怎么用 |
|---|---|
| WDNMD | 原句是带脏话的情绪输出；后来被善意改写成“我带你们打”“我都能蒙对”等。 |
| 我起了，一枪秒了，有什么好说的 | 自信对枪、一击制胜后的标准庆祝语；也常在蒙到一枪时使用。 |
| A1高闪来一个好吗？秋梨膏 | Mirage A1要高闪。“求你了”被口音空耳成“秋梨膏”。[梗词条考据](https://moegirl.icu/zh-cn/%E5%8F%8D%E6%81%90%E7%B2%BE%E8%8B%B1%E7%B3%BB%E5%88%97/%E6%A2%97) |
| 我都不知道这把狙究竟在架谁 | 吐槽架点毫无作用，敌人都走到脸上了还没反应。 |
| 我柜子动了，我不玩了 | 茄子玩恐怖游戏时被吓到的名场面；用于表示真的怂了。[出处梗概](https://www.moyuoo.com/archives/3335.html) |
| 真不戳 | “真不错”的口音版本；夸任何舒服、漂亮、有节目效果的东西。 |
| 真就××啊 | 万能茄式句型，如“真就白给啊”“真就一枪不开啊”。 |
| 茂名磨刀石 | 茄子来自茂名，又经常被人刀，故称“磨刀石”。 |
| 白给少年 | 茄子的代表性称呼之一；也泛指经常免费送人头的玩家。 |
| 我带你们打 | WDNMD的文明谐音版本，常用来假装主播非常团结友爱。 |

## 三、玩机器 / 6657直播间体系

“6657”原本是玩机器的直播间号，后来也可以直接代指这套弹幕文化。它的核心不是单独一句台词，而是一本正经地复读荒谬逻辑、选手亲属关系和失败名场面。

| 梗/语录 | 含义 |
|---|---|
| 你们不是懂CSGO吗？ | 玩机器被弹幕教练、事后诸葛亮折磨到破防的经典句式。现在用于反问那些特别懂、什么都能挑错的观众。[名梗出处切片](https://www.bilibili.com/video/BV17j41197x5/) |
| 刘氏家族 | 因玩机器本名刘亦博，弹幕把他喜欢或经常谈论的选手强行编入刘家族谱。 |
| 刘农 | device的6657中文名。玩机器是device粉丝，经常称其为“父亲”；状态差、大狙“流脓”，遂变成刘农。 |
| 阿汤哥 | device长相神似汤姆·克鲁斯，是其中文圈常用外号。 |
| 人类极限 | 对巅峰device的赞美：在s1mple、ZywOo这类“外星人”之下，凡人能达到的极限。 |
| 类人极限 | “人类极限”的倒转版；device发挥很差时，调侃只勉强像个人类玩家。[相关外号解释](https://www.dust2.us/news/65039/who-do-chinese-fans-call-niko-a-soft-legged-shrimp-exploring-chinese-player-nicknames) |
| 越勾越搜 | 一本正经的“CS哲学”：钩子/老六藏得越久，对面就搜得越仔细。多用于计划失败后的总结。 |
| 鱼越大，鱼越小 | 经典荒谬相对论：“鱼越大，鱼刺越大；鱼刺越大，肉越少；肉越少，鱼越小。”并非CS战术，但6657高频。 |
| 真正关键的来了 | 播放选手生涯回顾时，终于要放到那次致命空枪、被翻盘或重大失败了。 |
| 这××有力气 | 看到枪法、集锦、音乐或剪辑冲击力很强时刷；是外部热梗在CS切片中的融合。 |
| 纯粹的CS享受 | 比赛对枪、战术和残局质量很高时可以真心说；弹幕满屏烂梗时也可反讽。 |
| 玩小将 | 玩机器观众的常用称呼，语气可以是自称，也可以带调侃。 |
| 6657大厦/节奏大厦 | 弹幕围绕某件事连续盖楼、带节奏；烂梗刷屏有时反而会把严肃节奏冲走。 |

## 四、其他中文主播梗

| 主播/梗 | 解释 |
|---|---|
| 马西西：GNLS | 带脏话的拼音缩写，功能类似WDNMD，用于崩溃或吐槽。[含义说明](https://m.sohu.com/a/333671549_120099884/) |
| 马西西：我顶你个钢盔 | 马式情绪感叹；“钢盔”也成为其代表性元素。 |
| CSBOY | 马西西与MO等组成的赛事解说组合，特点是专业分析和聊天整活并存。 |
| QUQU：太常规了 | 打出精彩操作后故作平静：这只是常规操作。后来失误时也会被弹幕反向刷。[相关介绍](https://www.sohu.com/a/404718128_120099885) |
| QUQU：佳慧倒水 | 对妻子佳慧喊话的直播日常，后来成为直播间固定复读语。 |
| QUQU：我发财了 | 捡到好枪、开出好东西或局势突然变好时使用。 |
| 王喜顺：啊对对对 | 完整版通常接“希望你对你的人生也是这个态度”，用于回击嘴硬队友。 |
| 疯狂偷吃你的贡品 | 王喜顺回击弹幕的夸张狠话，后来演变成“净坛使者”等称呼。 |
| 冬瓜强：甲亢巨人 | 因其情绪激动、音量很大而来的老梗；涉及本人健康状况，最好只在熟悉该梗的圈内使用。 |

## 使用速记

操作好就叫“神、爹、人类极限”，操作差就叫“白给、海参、类人极限”；赢一回合“计划有变准备夺冠”，输一回合“de_airport已加载”；不知道刷什么时，刷“太常规了”通常不会错。

## 使用提醒

- WDNMD、GNLS等本质上是脏话缩写，不建议对陌生人或在正式场合使用。
- “软脚虾”“海参”“类人极限”等属于贬义调侃，应区分评价比赛表现和人身攻击。
- 涉及选手、主播健康状况或未经证实的队内传闻时，不应把圈内梗当成事实传播。
- 烂梗具有很强的时效性；相同词语在不同直播间可能有不同含义。
